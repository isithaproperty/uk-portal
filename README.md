# UK Managing Agent Portal

A responsive UK residential managing-agent portal covering portfolio operations, maintenance, resident services, service charges, communications, and Building Safety Act / Golden Thread workflows.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import this repository into Vercel. Vercel will detect Next.js automatically; no custom build settings are required.

The current release is a front-end working prototype using demonstration records. Authentication, document storage and live operational data will be connected in the next development stage.
